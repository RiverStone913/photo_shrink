# 사진 용량 줄이기

여러 장의 사진(JPG, PNG, WebP) 용량을 한 번에 줄이는 웹앱입니다.

- 목표 용량(예: 500KB 이하) 또는 화질(%)을 기준으로 줄이고, 긴 변 크기(1920px 등)도 정할 수 있습니다.
- 원래 파일 형식을 그대로 유지합니다. 사진마다 저장하거나 ZIP으로 한 번에 받을 수 있습니다.
- **모든 처리는 내 브라우저 안에서만 이루어지며, 사진은 어떤 서버로도 업로드되지 않습니다.**
- 줄인 사진에서는 촬영 위치 등 EXIF 정보가 지워집니다.
- 사용 라이브러리(lib 폴더에 포함): JSZip 3.10.1
